# Contribution graph

`tools/render-contrib.mjs` renders the **last 30 days** of contributions as an
isometric SVG. No dependencies and no third-party action — it runs on Node's
built-in `fetch` against the GitHub GraphQL API.

Outputs, regenerated by `.github/workflows/contrib-graph.yaml`:

    assets/contrib-graph/contributions-3d.svg        (light)
    assets/contrib-graph/contributions-3d-dark.svg   (dark)

The README embeds both via `<picture>`, so it follows the viewer's theme.

## Running it locally

    GITHUB_TOKEN=<pat> node tools/render-contrib.mjs --user deepakvamsi

A classic PAT with no scopes ticked is enough for public contribution data.
For a preview with synthetic data and no token:

    node tools/render-contrib.mjs --mock --out preview/sample.svg

## Options

    --user <login>   whose contributions to fetch (default: deepakvamsi)
    --out <path>     light-variant output path; dark gets "-dark" appended
    --mock           synthetic data, no token required

Change `DAYS` at the top of the script for a window other than 30.

## Schedule

Daily at 18:00 UTC, on manual dispatch, and whenever the workflow or the
renderer itself changes. The commit step is a no-op when the SVG is unchanged.
